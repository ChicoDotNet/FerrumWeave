# Support

FerrumWeave is currently **pre-alpha / architectural discovery**. There is not yet a production compiler, SDK, or supported runtime surface.

That distinction matters when asking for help.

## Use GitHub issues for

- reproducible repository or website bugs;
- documentation problems;
- architecture questions that should become part of the public record;
- design proposals;
- upstream compatibility findings;
- future compiler/SDK bugs once those components exist.

Before opening an issue, search existing discussions to avoid fragmenting the same problem across several threads.

## Do not use public issues for

- security vulnerabilities with weaponizable details;
- Code of Conduct reports containing sensitive personal information;
- credentials, secrets, private customer information, or proprietary source code.

See [`SECURITY.md`](SECURITY.md) and [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) for private-reporting guidance.

## Questions are welcome

You do not need to be expert in both Rust and .NET to participate.

If a question comes from a Rust mental model, say so. If it comes from a .NET mental model, say so. Cross-ecosystem questions are part of the project, not noise around it.

A useful question often includes:

- what you are trying to accomplish;
- which ecosystem assumptions you are bringing with you;
- what behavior you expected;
- what evidence or documentation you have already checked.

## No production SLA yet

FerrumWeave currently provides no commercial support commitment, response-time SLA, compatibility guarantee, or production-readiness promise.

When those guarantees become real, they will be documented explicitly rather than implied by the existence of the repository.
