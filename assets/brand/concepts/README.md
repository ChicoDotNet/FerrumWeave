# FerrumWeave Concept Boards

These boards preserve the project's early visual exploration so future contributors can distinguish intentional brand decisions from accidental styling.

They are **reference artwork**, not yet final production masters. The PNG files are the preserved source references for this exploration. Future SVG/vector and web-optimized derivatives should be created from the strongest ideas here while improving geometry, typography, accessibility, and small-size rendering.

| File | Role |
|---|---|
| `01-ferrum-ox-woven-ring.png` | **Primary direction / visual north star.** Ferrum Ox carrying/supporting the woven interoperability ring. |
| `02-ferrum-ox-brand-guide.png` | Mascot, silhouette, two-color treatment, wordmark, palette, and woven emblem exploration. |
| `03-ferrumweave-icon-exploration.png` | Woven knot, ox+weave, Ferrum Ox, app-icon, favicon, and monochrome exploration. |
| `04-ferrumweave-merch-exploration.png` | One-color/two-color apparel and community merchandise feasibility. |

Do not overwrite these source references with optimized derivatives. Production assets belong in the corresponding `logos/`, `mascot/`, `icons/`, `hero/`, or `merch/` directories as they are created.

See [`docs/brand/README.md`](../../../docs/brand/README.md) for the current visual-direction contract.
