# FerrumWeave Concept Boards

These boards preserve the project's early visual exploration so future contributors can distinguish intentional brand decisions from accidental styling.

They are **reference artwork**, not yet final production masters. Future SVG/vector assets should derive from the strongest ideas here while improving geometry, typography, accessibility, and small-size rendering.

| File | Role |
|---|---|
| `01-ferrum-ox-woven-ring.webp` | **Primary direction.** Ferrum Ox carrying/supporting the woven interoperability ring. |
| `02-ferrum-ox-brand-guide.webp` | Mascot, silhouette, two-color treatment, wordmark, palette, and woven emblem exploration. |
| `03-ferrumweave-icon-exploration.webp` | Woven knot, ox+weave, Ferrum Ox, app-icon, favicon, and monochrome exploration. |
| `04-ferrumweave-merch-exploration.webp` | One-color/two-color apparel and community merchandise feasibility. |

See [`docs/brand/README.md`](../../../docs/brand/README.md) for the current visual-direction contract.
